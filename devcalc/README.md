# DevCalc

The developer calculator that this lesson series builds. Each lesson adds one more part.

## Current stage: Lv1 radix converter (lesson 01)

```bash
node devcalc/src/main.ts 255
# HEX : 0xFF
# DEC : 255
# BIN : 0b11111111

npm test        # DevCalc tests
```
